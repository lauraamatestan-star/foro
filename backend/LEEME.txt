MAPA DEL BACKEND (Laravel API) — empieza aquí
=============================================

routes/api.php           → Todas las URLs de la API (léelo primero).
app/Http/Controllers/    → Toda la lógica + validación ($request->validate):
  AuthController.php     Login, registro, recuperar contraseña
  ThreadController.php   Hilos, categorías, votos, bookmarks, reportes
  ReplyController.php    Respuestas
  ProfileController.php  Perfil, imágenes, guardados, contraseña
  UserController.php     Perfil público
  AdminController.php    Moderación
  GoogleAuthController.php OAuth (redirect/callback)
app/Models/              → User, Thread, Reply, Category, Vote...
app/Services/            → VoteService, RoleService
database/migrations/     → Estructura de la base de datos
database/seeders/        → Datos de demo (demo@foro.test / password123)

Comandos útiles:
  php artisan migrate
  php artisan db:seed
  php artisan serve
