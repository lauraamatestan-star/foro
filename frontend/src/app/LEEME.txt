MAPA DEL FRONTEND (Angular) — empieza aquí
============================================

foro.api.ts     → Tipos + servicios HTTP + login + guards. Todo lo que habla con el backend.
foro.ui.ts      → Botones, votos, karma, markdown, árbol de respuestas. Piezas visuales reutilizables.
app.component.ts → Cabecera (nav), búsqueda, pie legal.
app.routes.ts   → Qué URL abre qué pantalla.

pages/          → Una pantalla = un par .ts + .html (opcional)
  feed.page       Inicio, listado de hilos
  thread.page     Detalle de un hilo + respuestas
  thread-new.page Crear hilo
  login.page      Entrar
  register.page   Registro
  forgot.page     Olvidé contraseña
  reset.page      Nueva contraseña
  google.page     Callback de Google
  profile.page    Tu perfil
  user.page       Perfil público de otro usuario
  admin.page      Panel admin
  legal.page      Privacidad / términos

main.ts         → Arranca la app (no hace falta tocarlo al principio).

Flujo típico: usuario abre feed → thread → profile.
Cambiar textos/estilos: pages/*.html o plantillas en pages/*.ts.
